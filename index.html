01

Business Case

SaaS businesses depend on recurring customers. The objective of this analysis is to identify users showing declining engagement, understand which customer segments contribute to churn, and quantify the associated recurring-revenue impact.

→ Identify customers who have churned or are at elevated churn risk.
→ Analyze product engagement before customer churn.
→ Measure recurring revenue exposed to customer attrition.
→ Surface actionable patterns for retention teams.

churn_analysis.sql
SQL 
WITH latest_subscription AS (
  SELECT
    user_id,
    end_date,
    mrr,
    ROW_NUMBER() OVER (
      PARTITION BY user_id
      ORDER BY end_date DESC
    ) AS rn
  FROM subscriptions
),
churned_users AS (
  SELECT
    u.user_id,
    u.plan_type,
    s.end_date,
    s.mrr
  FROM users u
  JOIN latest_subscription s
    ON u.user_id = s.user_id
  WHERE s.rn = 1
    AND s.end_date < CURRENT_DATE
)
SELECT *
FROM churned_users
ORDER BY mrr DESC;
data_cleaning.py
PYTHON 
import pandas as pd

df = pd.read_csv("product_events.csv")

# Normalize column names
df.columns = (
    df.columns
      .str.strip()
      .str.lower()
      .str.replace(" ", "_")
)

# Convert dates safely
df["event_date"] = pd.to_datetime(
    df["event_date"], errors="coerce"
)

# Remove duplicate events
df = df.drop_duplicates(
    subset=["user_id", "event_date", "event_name"]
)

# Handle missing session duration
df["session_minutes"] = df["session_minutes"].fillna(0)
