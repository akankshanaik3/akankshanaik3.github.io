01

Business Case

SaaS businesses depend on recurring customers. This analysis focuses on understanding customer engagement, subscription behavior and patterns associated with churn.

→ Identify churned customers.
→ Analyze engagement before churn.
→ Measure recurring revenue associated with customers.
→ Identify customer segments requiring attention.

Analytical Questions

Segment customers by plan, tenure and activity.

What patterns exist?

Compare engagement between customer groups.

What revenue is exposed?

Quantify MRR associated with churned customers.

Where should teams act?

Highlight segments requiring further investigation.

03

Dataset & Data Model

Three related datasets connect customer information, product activity and subscription revenue.

WITH latest_subscription AS (

  SELECT
    user_id,
    end_date,
    mrr,

    ROW_NUMBER() OVER (
      PARTITION BY user_id
      ORDER BY end_date DESC
    ) AS rn

  FROM subscriptions
)

SELECT
  u.user_id,
  u.plan_type,
  s.end_date,
  s.mrr

FROM users u

JOIN latest_subscription s
  ON u.user_id = s.user_id

WHERE s.rn = 1
  AND s.end_date < CURRENT_DATE

ORDER BY s.mrr DESC;
import pandas as pd

df = pd.read_csv("product_events.csv")

# Normalize column names
df.columns = (
    df.columns
      .str.strip()
      .str.lower()
      .str.replace(" ", "_")
)

# Convert event dates
df["event_date"] = pd.to_datetime(
    df["event_date"],
    errors="coerce"
)

# Remove duplicate events
df = df.drop_duplicates()

# Handle missing session duration
df["session_minutes"] = (
    df["session_minutes"]
      .fillna(0)
)
